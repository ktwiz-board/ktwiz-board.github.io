# KBO 정규시즌 예측 도구

wiz board 가을야구 섹션의 확률 계산을 **내 컴퓨터에서 조건을 바꿔 가며** 돌려보는 명령줄 도구입니다.
외부 패키지 없이 Node 18 이상만 있으면 됩니다. 데이터는 보드 수집기와 같은 네이버 스포츠 일정 API에서 받고,
하루 한 번 `cache/`에 저장합니다(저장소에는 올라가지 않음).

## 명령

```bash
node tools/predictor/predict.js form                 # 팀별 최근 폼 (--window 60 등으로 변경)
node tools/predictor/predict.js ag                   # 아시안게임 차출 선수별 세부 지표와 팀별 공백 영향
node tools/predictor/predict.js backtest             # 어떤 설정이 올 시즌 실제 경기를 가장 잘 맞혔나
node tools/predictor/predict.js sim                  # 잔여 시즌 시뮬레이션 (최종 순위 확률 + KT 경기차 전망, 차출 공백 반영)
node tools/predictor/predict.js sim --window 30 --form 0.7 --n 50000 --rival 삼성 --no-ag
```

| 옵션 | 의미 | 기본값 |
|---|---|---|
| `--window` | 최근 폼을 볼 경기 수 (`season`이면 시즌 전체만) | 60 |
| `--form` | 전력에서 최근 폼의 비중 (0~1, 나머지는 시즌 전체) | 0.3 |
| `--regress` | 리그 평균(.500)으로 끌어당기는 정도 — 운으로 부풀려진 성적 보정 | 0.3 |
| `--no-ag` | (sim) 아시안게임 차출 공백 반영 끄기 | |
| `--ag-return` | (sim) 차출 선수 복귀일 — 이 날짜 전 경기만 공백 전력 | 2026-09-28 |
| `--home` | 홈팀 승률 가산 | 0.02 |
| `--n` | 시뮬레이션 횟수 | 20000 |
| `--rival` | 경기차를 비교할 팀 | KT 제외 승률 1위 |
| `--from` | (backtest) 채점 시작일 | 2026-05-15 |
| `--windows`, `--weights` | (backtest) 비교할 창 크기·폼 비중 목록 | `10,20,30,45,60` / `0.3,0.5,0.7,1` |
| `--refresh` | 오늘 캐시를 무시하고 경기 데이터를 다시 받기 | |

## 모델

- **팀 전력** = 최근 N경기(승률·피타고리안 기대승률 반반) × 폼 비중 + 시즌 전체(피타고리안 70%·승률 30%) × (1 − 폼 비중), 그다음 리그 평균으로 회귀
- **한 경기 승률** = log5(홈 전력, 원정 전력) + 홈 가산
- **시뮬레이션**: 리그 잔여 일정 전체를 날짜순으로 굴려 모든 팀의 최종 성적을 만든다. 아직 편성되지 않은 경기는 리그 평균 상대와 치르는 것으로 마지막에 더한다.
- **백테스트**: 5월 중순 이후 모든 경기를 "그 전날까지의 데이터로만" 예측해 채점한다(미래 정보 누설 없음).
  - logloss·Brier: 경기 단위 확률 예측 정확도
  - 향후 20경기 승률 오차: 경기차 전망에 더 가까운 지표

## 백테스트 결과 요약 (2026-09-25, 455경기 채점)

| 설정 | logloss (↓) | 향후 20경기 승률 오차 (↓) |
|---|---|---|
| 시즌 전체 + 회귀 0.3 | **0.6797** | .1075 |
| 최근 60경기 × 30% + 회귀 0.3 | 0.6798 | .1084 |
| 최근 30경기 × 30% | 0.6821 | .1086 |
| 최근 30경기 × 70% (현재 보드 전망 차트) | 0.6878 | .1128 |
| 최근 30경기 × 100% | 0.6949 | .1170 |
| 동전 던지기 | 0.6931 | .1196 |

**최근 경기만 크게 믿을수록 오히려 덜 맞았다.** 30경기 폼만 쓰면 동전 던지기보다도 못하고,
창을 60경기로 늘리거나 시즌 전체 비중을 높일수록 좋아진다. 최근 30경기의 성적 차이는 대부분 운(표본 잡음)이라는 뜻이다.
다만 모델 간 차이 자체는 작다 — 야구 한 경기는 원래 운의 비중이 커서 어떤 모델도 적중률 55~57% 근처가 한계다.

기본값(60경기 × 30%, 회귀 0.3)은 이 결과를 따른 것이고, 보드의 경기차 전망 차트도 같은 설정을 쓴다.

## 아시안게임 차출 공백 (`ag`, `sim` 기본 반영)

명단은 [`ag-2026.json`](ag-2026.json)에 있다(소집 9/14, 대회 9/21~26, 리그 중단 없음). 선수별 시즌 성적은 KBO 공식 기록실에서 받는다.

- **타자**: wOBA(선형 가중치)로 리그 평균 대비 득점을 구하고 대체선수 보정(600타석당 20점)을 더한 뒤, 경기당 타석으로 나눠 "빠지면 경기당 잃는 득점"
- **투수**: 실점률(RA9)과 대체선수 실점률(리그 평균 × 선발 1.3 / 불펜 1.15)의 차이 × 경기당 이닝. 10세이브 이상은 ×1.7, 10홀드 이상은 ×1.3 레버리지
- **팀 전력 변화**: 경기당 득점·실점을 그만큼 옮겨 피타고리안 승률을 다시 계산
- **시뮬레이션 반영**: 공백 기간(9/14~)에 치른 경기가 폼·시즌 성적에 섞여 있으므로 그 몫을 되돌려 "완전체" 전력을 만들고, 복귀일 전 경기만 공백 전력으로 굴린다
- 수비·주루·포지션 가치는 공개 기록만으로 추정하기 어려워 **제외** — 수비형 선수(유격수·포수 등)는 과소평가될 수 있다
